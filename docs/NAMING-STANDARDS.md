# Naming Standards

Application: MediaVault
Repository: flexpath-final-project-mediavault-christopher-h

Use descriptive names.
Avoid ambiguous folder/file pairs with the same name.

Examples:
- MediaItem.java
- MediaCollection.java
- MediaItemController.java
- MediaCollectionController.java
- DashboardPage.jsx
- ItemsPage.jsx
- CollectionsPage.jsx
